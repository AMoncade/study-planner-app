# Study Creator

Turn your class materials (PDFs, text files, photos of notes) into study guides, flashcards, and practice tests automatically. Works on your computer and your phone.

## What it does

1. Create a class (e.g. "BIO 201").
2. Upload materials: PDFs, `.txt`/`.md` files, or photos of handwritten notes.
3. The app extracts the content once (AI handles OCR and handwriting).
4. One tap generates a **flashcard deck**, a **practice test**, or a **study guide**.
5. Study: review flashcards with Anki-style spaced repetition, take graded quizzes with explanations, read/download the guide. Export cards to Anki (TSV).

## Run it locally

```bash
npm install
npx prisma db push      # creates the SQLite database
npm run dev             # http://localhost:3000
```

By default the app expects a local [Ollama](https://ollama.com) engine (see below) so real AI runs entirely on your PC, for free, with no account and no API key. The dashboard shows a banner confirming the AI engine is connected, or telling you what command to run if it isn't.

## Set up the AI (Ollama)

Ollama runs the language model on your own computer — no cloud, no API key, no per-document cost once the models are downloaded.

1. Install Ollama from [ollama.com](https://ollama.com).
2. Pull a text model (used for flashcards, quizzes, and study guides):
   ```bash
   ollama pull llama3.1
   ```
3. Optional — pull a vision model if you want to OCR photos of handwritten or printed notes:
   ```bash
   ollama pull llama3.2-vision
   ```
4. Make sure Ollama is running (`ollama serve`, or just open the Ollama app), then start Study Creator as usual. The dashboard banner will confirm it's connected.

This is **PC-only** (the model runs on the machine hosting the app) and fully offline/free once the models are downloaded. `.env` already defaults to `AI_PROVIDER="ollama"`; see `.env.example` for the `OLLAMA_HOST` / `OLLAMA_MODEL` / `OLLAMA_VISION_MODEL` overrides.

## Other AI options

- **Zero setup:** set `AI_PROVIDER="offline"` in `.env` to skip AI entirely. Text files and typed PDFs still work, and cards/quizzes/guides are generated by simple rules instead of a model — good for kicking the tires with nothing installed.
- **Cloud API:** set `ANTHROPIC_API_KEY` (and optionally `AI_PROVIDER="anthropic"`) to use Claude in the cloud instead of local Ollama. Cost is usage-based, roughly 1–5 cents per document.

## Use it on your phone

- **Now (local network):** run `npm run dev` and open your computer's LAN IP (e.g. `http://192.168.1.x:3000`) in your phone's browser while on the same Wi-Fi.
- **Anywhere (deploy):** deploy to Vercel and switch `DATABASE_URL` to a hosted Postgres (Neon/Supabase free tier). Then "Add to Home Screen" on your phone. See `PLAN.md` (Phase 3) for the deployment steps.

## Tech

Next.js 15 (App Router) · TypeScript · Tailwind CSS · Prisma + SQLite · Ollama (local) with optional Anthropic Claude API.

## Project layout

- `src/lib/ai.ts` — extraction + generation (offline heuristics, local Ollama, or Anthropic)

- `src/lib/srs.ts` — SM-2 spaced-repetition scheduler
- `src/app/api/**` — REST endpoints
- `src/app/**` — dashboard, class, deck, quiz, guide pages
- `prisma/schema.prisma` — data model
